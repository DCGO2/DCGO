# DCGO custom patching tool

Reapplies this fork's custom work onto a new official DCGO branch (`origin/develop` or a Public release).

Modules:

- **android** — Gradle/plugins, StreamingAssets textures, mobile UI packs, touch/audio helpers
- **ranked** — PlayFab ladder, ranked queue, MMR UI
- **tournament** — 4/8/16 player single-elim, Bo3
- **chat** — in-battle PvP chat
- **reconnect** — Photon `ReconnectAndRejoin`, PlayerTtl, opponent hold
- **friends** — Home friend list, PlayFab/local storage, online direct duel Bo1/Bo3

Visual-only extras (Blocker bubbles, ParticleDNA) are **not** in this tool.

Licensed / open-source-locked packs (**Sound**, **SCI-FI UI Components**, **DigitalEnvironmentEffects**) are **optional**. They are never exported into patches or the portable zip. Put them in a local folder before `apply` if you have them; if the folder is missing, apply still succeeds.

Baseline recorded in `config.json`: **Public 1.17.3** (`6faae89a7`).

## Commands

Run from the repo root in PowerShell:

```powershell
.\tools\dcgo-patch\dcgo-patch.ps1 export -IncludeUncommitted
.\tools\dcgo-patch\dcgo-patch.ps1 apply
.\tools\dcgo-patch\dcgo-patch.ps1 apply -LocalAssets CustomAssets
.\tools\dcgo-patch\dcgo-patch.ps1 rebase -Onto origin/develop
.\tools\dcgo-patch\dcgo-patch.ps1 status
.\tools\dcgo-patch\dcgo-patch.ps1 verify
```

Or: `.\dcgo-patch.bat export -IncludeUncommitted`

| Command | What it does |
|---|---|
| **export** | Diff current tree vs the baseline. Writes unified diffs under `patches/files/`, `overlay-files.json` (new/replaced files), and `regions.json` (DCGO-CUSTOM blocks). Optional licensed packs are excluded. |
| **export -Portable** | Also copies overlay files into `PATCHWorkspace/` and zips them (needed if you apply onto a zip/clone that does not have your custom branch). |
| **export -IncludeUncommitted** | Include working-tree edits (reconnect) in patches and overlay lists. |
| **apply** | Copy required overlays, optionally copy packs from `CustomAssets/` (or `-LocalAssets`), `git apply --3way` patches, then replace/insert `DCGO-CUSTOM` regions. Writes `PATCHWorkspace/apply-report.md`. |
| **rebase** | `git fetch`, branch `custom/<onto>` from `-Onto`, cherry-pick every commit after the baseline from `customBranch`. Best path for Android + Git LFS. |
| **status** | Baseline, ahead/behind official, overlay presence, optional-asset folder. |
| **verify** | Baseline exists, required overlay paths exist, markers present where expected. Optional packs are informational only. |

## Optional local assets

Configured in `config.json` as `localAssetsRoot` (default `CustomAssets`) and `optionalAssets`.

Mirror repo paths under the local root (gitignored):

```
CustomAssets/
  Assets/Sound/
  Assets/SCI-FI UI Components/
  Assets/Effect/DigitalEnvironmentEffects/
```

```powershell
# before apply on a machine that has the packs:
.\tools\dcgo-patch\dcgo-patch.ps1 apply -LocalAssets CustomAssets

# or point at the repo itself if the packs already live under Assets/:
.\tools\dcgo-patch\dcgo-patch.ps1 apply -LocalAssets .
```

If `CustomAssets/` (or `-LocalAssets`) is missing, apply skips those packs and continues. Magenta UI / missing audio may remain until the packs are provided.

## Next official version

Prefer rebase (keeps Android binaries and LFS):

```powershell
git fetch origin
.\tools\dcgo-patch\dcgo-patch.ps1 rebase -Onto origin/develop
```

If a cherry-pick stops on conflicts:

1. Resolve the listed files (Unity YAML: take custom scene/prefab overlays when unsure).
2. `git add` the resolved files, then `git cherry-pick --continue`.
3. Repeat until the remaining SHAs are applied.

If rebase is not usable (fresh zip of official source):

```powershell
# from the custom branch, once:
.\tools\dcgo-patch\dcgo-patch.ps1 export -IncludeUncommitted -Portable

# on the new official tree:
.\tools\dcgo-patch\dcgo-patch.ps1 apply
# optional: drop licensed packs into CustomAssets/ first
```

Then open Unity, fix anything in `PATCHWorkspace/apply-report.md`, and retarget patches:

```powershell
.\tools\dcgo-patch\dcgo-patch.ps1 export -IncludeUncommitted
```

Update `config.json` `baselineCommit` / `baselineLabel` to the official SHA you just patched onto.

## How patches survive official edits

Custom injections in original C# files are wrapped as:

```csharp
// === DCGO-CUSTOM:ranked begin ===
RankedServices.EnsureExists();
// === DCGO-CUSTOM:ranked end ===
```

`apply` tries `git apply --3way` first. If a hunk fails, it replaces the matching region, or inserts it after the `anchors` listed in `modules/*.json`.

Prefabs and scenes (`Opening.unity`, BattleChat prefabs, ProjectSettings) are **whole-file overlays**, not line patches.

## Layout

```
tools/dcgo-patch/
  dcgo-patch.ps1
  config.json
  modules/*.json
  patches/files/*.patch    generated by export (one combined diff per official file)
  overlay-files.json       generated by export (new/replaced files)
  regions.json             generated by export (DCGO-CUSTOM blocks)
  series/                  rebase uses cherry-pick, not format-patch (Android is too large)
PATCHWorkspace/            gitignored; apply report + portable zip
CustomAssets/              gitignored; optional licensed packs for apply
```

Do not copy licensed Sound / SCI-FI / DigitalEnvironmentEffects into `tools/` or git. Keep them under `CustomAssets/` (or pass `-LocalAssets`). Required android overlays (Gradle, StreamingAssets textures, etc.) still export normally; rebase cherry-picks the android commit for LFS/binaries.
